# Padrão dos changelogs

Preferência aprovada em 05/11/2026:

- Usar sempre o layout **Major** nas novidades do launcher, inclusive em versões
  minor e patch. O tipo é uma escolha de apresentação; não altera a numeração.
- O layout Standard deixa de ser usado nos novos changelogs.
- Reaproveitar a arte atual quando não houver pedido de outra imagem. Cada
  release deve ter sua própria cópia no armazenamento, para evitar que editar
  uma imagem remova a arte de outra versão.
- Revisar os cinco idiomas e manter os destaques curtos. Colocar a lista
  completa em “Ver todas as mudanças”.
- Nas notas para o usuário, incluir apenas mudanças que afetam o launcher ou
  sua experiência. Informações administrativas ficam nas notas internas.
- Revisar e editar um rascunho não autoriza publicá-lo. Preservar o rascunho
  até haver pedido de publicação.

`UNRELEASED.md` reúne o que ainda precisa entrar em uma versão. As notas de
cada versão ficam no arquivo correspondente, como `2.4.24.md`.
