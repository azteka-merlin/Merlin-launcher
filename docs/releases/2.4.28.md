# Merlin 2.4.28

## Avisos de instabilidade

- Uma badge discreta informa quando Correções ou Adicionar jogos apresentam instabilidade confirmada.
- Clique na badge para ler os detalhes. Quando as duas áreas são afetadas, o painel lista cada problema separadamente.
- O painel fecha ao clicar fora ou pressionar Esc e desaparece quando não há incidentes.

## Correções

- Se um catálogo externo for pausado pela equipe, a aba mostra diretamente as correções próprias do Merlin e se atualiza sem reiniciar o Launcher.
- Imagens já salvas continuam disponíveis, e as imagens cadastradas para correções próprias agora são exibidas com mais consistência.
- As imagens das correções continuam aparecendo mesmo quando um catálogo externo está pausado.

## Adicionar jogos

- A consulta do estado dos manifestos foi melhorada para reduzir esperas desnecessárias ao adicionar jogos.

## Biblioteca

- A Biblioteca agora aproveita imagens já cadastradas para jogos que antes apareciam sem imagem, sem atrasar sua abertura.
- Jogos removidos do catálogo e já desinstalados não aparecem mais como disponíveis para baixar.
