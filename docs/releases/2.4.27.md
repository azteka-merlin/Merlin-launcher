# Merlin 2.4.27

## Avisos de instabilidade

- Uma badge discreta informa quando Correções ou Adicionar jogos apresentam instabilidade confirmada.
- Clique na badge para ler os detalhes. Quando as duas áreas são afetadas, o painel lista cada problema separadamente.
- O painel fecha ao clicar fora ou pressionar Esc e desaparece quando não há incidentes.

## Correções

- Se o catálogo externo for pausado pela equipe, a aba passa a mostrar diretamente as correções próprias do Merlin e se atualiza sem reiniciar o Launcher.
- Capas já salvas continuam disponíveis. Para jogos Steam sem capa local, a aba tenta a capa da Steam.

## Adicionar jogos

- Melhorada a consulta do estado dos manifestos para reduzir esperas desnecessárias ao adicionar jogos.

## Catálogo de jogos

- Jogos removidos do catálogo e já desinstalados não aparecem mais como disponíveis para baixar.
