# Merlin 2.5.0

## Saves sincronizados

- O histórico agora guarda até 10 backups completos por jogo, sem apagar as cópias antigas apenas por causa da idade.
- A versão atual e os backups completos podem ser baixados em ZIP. As cópias antigas parciais continuam disponíveis para restauração.
- A tela permite atualizar os dados do jogo e abrir a pasta local do save quando ela estiver disponível.
- Antes de restaurar, o Merlin preserva uma cópia de segurança do estado atual. Após a restauração, reinicia a Steam para sincronizar os arquivos.

## Meu acesso

- Os dados da licença aparecem de forma mais organizada, com a chave protegida até você escolher mostrá-la.
- Agora é possível atualizar nome, e-mail e telefone opcional. A troca de e-mail exige confirmação no novo endereço.

## Interface e suporte

- As telas de Biblioteca, Correções e Premium receberam uma barra de rolagem mais discreta.
- Os avisos de disponibilidade Premium agora usam o termo “ativações” de forma consistente.
- O relatório de suporte inclui mais detalhes das tentativas de adicionar jogos, ajudando a identificar falhas de instalação.
